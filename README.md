# WA Auto

**AI-Powered WhatsApp Automation**

Premium, mobile-first B2B SaaS frontend prototype built with:

- HTML5
- CSS3
- Vanilla JavaScript
- Inline SVG / CSS visuals
- Local mock data

## Run in SPCK Editor

1. Extract `WA-AUTO.zip`.
2. Open the `WA-AUTO` folder in SPCK Editor.
3. Open `index.html`.
4. Use SPCK Preview / Run.
5. No npm, Node.js, build command, framework, CDN, API key, or internet connection is required.

## Prototype scope

This version is frontend-only. WhatsApp Business API, AI models, n8n, CRM, database, authentication, webhooks, billing and real integrations are intentionally mocked.

The UI is structured so those services can be connected later through a real backend.

## Main screens

- Overview
- Inbox
- AI Agent
- Automations
- Contacts
- Knowledge Base
- Analytics
- Settings

## Files

`index.html` — application shell  
`css/style.css` — responsive design system and components  
`js/app.js` — mock state, rendering and interactions  
`assets/images/` — reserved for local images  
`assets/icons/` — reserved for local icons
